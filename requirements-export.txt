# Tier-2 pdf_render (Docling -> reportlab -> pypdfium2) is FULLY PERMISSIVE — no
# AGPL — and recovers figures via pypdfium2. Prefer it for PDF-only intake.

# reportlab (BSD) + Docling are already in the main/parsing requirements.

# AGPL-3.0 OR a paid Artifex commercial licence — a licence review gates shipping
# it in the commercial product. It is OPTIONAL: the default docx backend and the
# permissive Tier-2 pdf_render cover the common cases without it.
PyMuPDF>=1.26,<2         # AGPL-3.0 / commercial — OPTIONAL (Tier-1 overlay only)
