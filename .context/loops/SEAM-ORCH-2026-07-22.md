## Merge procedure per agent branch

1. `git merge --no-ff <branch>` from `feat/vision-delivery-2`. Conflicts should not occur (disjoint
   scopes); if one does, resolve preferring both sides, rerun that loop's tests.
2. Verify the loop's red→green evidence against its worksheet before accepting.
3. After all merges: the full-suite + ratchet pass above. A ratchet regression is fixed by tightening
   code, never by loosening the baseline.
4. `git worktree remove` each agent worktree; delete merged branches.
5. Push `feat/vision-delivery-2` to origin so the drift auditor can resolve SHAs.
