## 1. Task

`<RevisionIndicator>` ships role="note" + a static aria-label. The visible text is rich — "tracked · 5 changes · Dr. Reviewer · 3d ago" — but the static aria-label collapses that to a single phrase that's identical for all six fixture variants in the design system. Screen-reader users lose:
- Direction (moved out vs moved in vs both)
- Magnitude (1 vs 20 changes)
- Author count

This loop replaces the static aria-label with a dynamic, descriptive sentence built from the same state that drives the visible label.

**Addenda**: A1 (audit-by-default — direction is part of the audit signal), A7 (canonical IA — `/workspace/*` is the single surface a regulator inspects).

## 2. Spec — acceptance criteria

- [ ] AC-1: New exported helper `accessibleRevisionLabel(revisions: SegmentRevisions): string` returns:
  - tracked, 1 change, 1 author: `"Tracked change by {author}"`
  - tracked, ≥2 changes, 1 author: `"{N} tracked changes by {author}"`
  - tracked, ≥2 changes, 0 authors: `"{N} tracked changes"`
  - tracked, ≥2 changes, ≥2 authors: `"{N} tracked changes by {M} authors"`
  - tracked, 1 change, 0 authors: `"Tracked change"`
  - tracked, 1 change, ≥2 authors: `"Tracked change by {M} authors"`
  - moveFrom-only (any count): `"Text moved out of this segment by {author}"` (or `"by {M} authors"` / no by-clause)
  - moveTo-only: `"Text moved into this segment by …"`
  - moveFrom + moveTo: `"Text moved within this segment by …"`
- [ ] AC-2: When the count fields are absent (back-compat — older backend payload), helper falls back to `"Tracked change by {author}"` without a count (no "NaN changes" or "undefined changes" leaking).
- [ ] AC-3: `<RevisionIndicator>` consumes the helper for its `aria-label`. Visible text remains unchanged.

## 3. Design

```ts
// New helper, alongside totalRevisionCount in lib/api.ts (or a new
// presentation-side helper in components/ui/RevisionIndicator.tsx —
// component-local since the wire format is unchanged).
function accessibleRevisionLabel(revisions: SegmentRevisions): string {
  const { has_insertions, has_deletions, has_moves_from, has_moves_to } = revisions
  const total = totalRevisionCount(revisions)
  const authors = revisions.authors
  const byClause =
    authors.length === 0 ? "" :
    authors.length === 1 ? ` by ${authors[0]}` :
    ` by ${authors.length} authors`

  if (has_insertions || has_deletions) {
    if (total >= 2) return `${total} tracked changes${byClause}`
    return `Tracked change${byClause}`
  }
  if (has_moves_from && has_moves_to) return `Text moved within this segment${byClause}`
  if (has_moves_from) return `Text moved out of this segment${byClause}`
  if (has_moves_to) return `Text moved into this segment${byClause}`
  // Fallback (defensive — shouldn't reach here when component itself returned non-null).
  return `Segment carries tracked changes`
}
```

**Why component-local not in `lib/api.ts`**: this is presentation logic, not API shape. Keeping it co-located with the component that consumes it keeps the api.ts focused on wire types.

**Why "tracked changes" for plural and "tracked change" for singular**: matches everyday English; SR users won't hear "1 tracked changes". The visible text is deliberately terse ("tracked"); the a11y label is the accessible counterpart that's allowed to be a complete sentence.

## 6. Red team

- **Existing test brittleness**: pre-existing assertion `name: /tracked changes/i` was strict-plural. My singular-when-count<2 path broke it. Fix: relaxed regex to `/tracked change/i`. Same fix applied to the e2e (one of the 2 stub fixtures has no n_* and now produces singular). Intent of both tests preserved.
- **Empty-authors fixture**: `byClause = ""` — accessible name reads "Tracked change" / "Text moved out of this segment" with no trailing "by …". Reads cleanly.
- **No-flags fixture**: component returns null before reaching the helper, so the defensive fallback "Segment carries tracked changes" never gets emitted. Safe.
- **i18n**: aria-label is hardcoded English. TransMax UI is currently English-only; deferred when localisation lands.
- **Bundle impact**: one extra exported function, ~30 lines. Negligible.
