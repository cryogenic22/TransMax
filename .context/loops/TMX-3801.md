# TMX-3801 — Abbreviation/initial-aware segmenter + wire into PDF ingestion

**State**: `[Done]` — `4010531` on origin/main  ·  **Owner**: Document Pipeline  ·  **Sprint**: 2  ·  Fidelity step 1/3 (2026-06-04)
**Reversibility**: `two-way`. **Blast radius**: `app/services/segmenter.py` (harden), `app/services/pdf_service.py` (`_split_sentences` delegates). **G2**: the NEJM byline-shatter is reproduced as a red assertion first.

## 1. Task
Root-cause #1 of the unacceptable NEJM translation: the **PDF ingestion path** (`PDFService._split_sentences`) used a naive `(?<=[.!?])\s+(?=[A-Z0-9])` regex that shattered author bylines + credentials ("Fernando P. Polack, M.D., Stephen J. Thomas, M.D.") into junk fragments — and it **bypassed** the good `segmenter.py` the rest of the pipeline already uses. Fix without a heavy dep (no NLTK/spaCy): harden the regex segmenter for initials + credentials, and route PDF ingestion through it. Addenda A2 (segment accuracy underpins the gates), document-fidelity (E3).

## 2. Spec
- [x] AC-1: a middle-initial + credential byline ("…P. Polack, M.D., Stephen J. Thomas, M.D.…") segments as ONE unit.
- [x] AC-2: a single uppercase letter before a dot (`P.`, `N.`, `J.`) is treated as an initial — never a boundary.
- [x] AC-3: credentials (`M.D`, `Ph.D`, `B.Sc`, …) don't split a byline, but CAN end a sentence when a clear new sentence follows.
- [x] AC-4: `Drs.`, `Nr.`, `Rd.` handled; real sentence boundaries + decimals/dose abbrevs unchanged.
- [x] AC-5: `PDFService._split_sentences` delegates to `get_segmenter(language).segment(...)` (no more naive regex).
- [x] AC-6: existing segmenter tests still pass (no regression).

Out of scope: NLTK/spaCy backend (heavy dep, not needed — regex segmenter handles the observed cases); CJK rules (TMX-3802); the structure/table/figure loss (that's the FIDELITY-EVAL + round-trip work, separate).

## 3. Design
Add `_CREDENTIAL_ABBREVS` (M.D/Ph.D/B.Sc/…); add `Drs/Sr/Jr` to titles, `Nr/Rd/pp/al/Fig/Eq/Ref` to contextual; add a **single-uppercase-letter → initial** rule in `segment()` (skips boundaries like `P.`/`N.`). `PDFService._split_sentences` now calls the shared segmenter so PDF ingestion matches every other input. Credentials are contextual (split only before a clear new sentence), so a byline (`M.D.,` — comma, no whitespace-after-terminator) never splits, while `…, M.D. The results…` does.
