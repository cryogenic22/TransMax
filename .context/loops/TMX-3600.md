## 3. Design

**Redirect table** (final, ordered most-specific-first since Next.js evaluates in order):

```typescript
async redirects() {
  return [
    // ── Unambiguous one-to-one (308) ────────────────────────────────
    { source: '/document/:docId', destination: '/workspace/documents/:docId', permanent: true },
    { source: '/new',             destination: '/workspace/upload',           permanent: true },
    { source: '/dashboard',       destination: '/workspace',                  permanent: true },

    // ── Ambiguous (307) — destination will tighten in follow-up tickets ──
    // /translate/[jobId]: workspace has no /workspace/jobs/[id] yet (TMX-3603 builds it).
    // Land on the jobs list with a focus query param until then.
    { source: '/translate/:jobId', destination: '/workspace/jobs?focus=:jobId&action=translate', permanent: false },
    { source: '/review/:jobId',    destination: '/workspace/jobs?focus=:jobId&action=review',    permanent: false },
    // /knowledge: maps to /workspace/tools (knowledge base / glossary). 307 because
    // the IA may split this into /workspace/tools and /workspace/glossary later.
    { source: '/knowledge', destination: '/workspace/tools', permanent: false },
  ];
}
```

**Why no redirect for `/design-system`**: dev-only diagnostic page; not user-facing. A future cleanup (TMX-3604) will move it to `/workspace/design-system` or remove from production routing entirely. Adding a redirect now signals "this is a public path" which it isn't.

**Why no redirect for `/` and `/login`**: landing and auth flow stay at the top level by convention. The workspace IA starts post-auth.

**Why permanent (308) vs temporary (307) split**:
- 308: tells search engines and SDK consumers "update your pointers; this is the new canonical URL forever."
- 307: tells them "this is a temporary stand-in; check back periodically." Used for routes whose destinations will tighten when per-page migration tickets land.

**Why preserve query strings in the ambiguous mappings (`?focus=:jobId&action=translate`)**: gives the `/workspace/jobs` page a hint to scroll-and-highlight the right job until the dedicated `/workspace/jobs/[id]` page exists. Failing loud is better than silently dropping the jobId on the floor.
