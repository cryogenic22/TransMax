## 1. Task

TMX-3408 fixed a substring-`in` numeric-check bug in `SpanishPack.check_numbers`: an order-of-magnitude tamper (`10 mg` → `100 mg`) was passing silently because `"10" in "100 mg"` is True. The Loop 2 red-team confirmed the **exact same bug is present in 7 other language packs** — every active language pair we ship is silently failing on critical-safety dose tampering.

Affected files:

```
app/services/language_packs/german.py:37            (substring `in`)
app/services/language_packs/french.py:41            (substring `in`)
app/services/language_packs/portuguese.py:79        (substring `in`)
app/services/language_packs/korean.py:67            (substring `in`)
app/services/language_packs/chinese.py:79           (substring `in`)
app/services/language_packs/japanese.py:50          (substring `in`, plus full-width digit translate)
app/services/language_packs/factory.py:66           (substring `in`, GenericLanguagePack default)
```

Per addendum A3 (no silent fallbacks in regulated paths), this is the canonical worst-case failure mode for a regulated translation product. **Must close before Sprint 1 ends.**

**Blast radius**: every translation in DE/FR/PT/KO/ZH/JA/AR (Arabic uses `factory.py` Generic), plus every fallback into the Generic default — the entire active pair set minus EN→ES (which TMX-3408 fixed inline).

**Addenda at play**: A2 (quality at deterministic gates), A3 (no silent fallbacks).

## 3. Design

**Helper signature** (added to `BaseLanguagePack` in `app/services/language_packs/base.py`):

```python
def _find_missing_numbers(
    self,
    source_text: str,
    target_text: str,
    *,
    accept_decimal_swap: bool = False,
    digit_translate: dict[str, str] | None = None,
) -> list[str]:
    """
    Return source-extracted numbers NOT preserved word-bounded in target.

    Critical safety semantic: a number is "preserved" only if its exact
    digit run appears bracketed by non-digits in the target. Substring
    `in` is unsafe (e.g. '10' is contained in '100'); this helper exists
    so the entire pack hierarchy stops repeating that mistake.
    See TMX-3408 / TMX-3410.
    """
```

**Why a base helper, not 7 inline rewrites**: 7 near-identical implementations is past the threshold where duplication > abstraction cost. Centralising means the *next* class-of-defect insight (e.g. Unicode digit normalisation, NFKC, Eastern Arabic numerals) lands in one place. Surgery vs entropy: this is the surgical move now even though the patch is wider.

**Why not consolidate `check_numbers` itself into the base**: the per-pack `check_numbers` carries pack-specific defect-message wording that's user-facing; reviewers need to know which gate (Korean / Japanese / etc.) caught the defect. Returning just the missing-numbers list from the helper preserves that.
