## 1. Task

Per addendum A8: prompts in `app/agents/prompts.py` are inline Python string constants today. EU AI Act technical documentation (live 2026-08-02) requires that any audit event from any past run must be answerable to "which exact prompt produced this output?" — a class-level Python constant doesn't carry that signal beyond `git blame` on a single file. Worse, edits to a constant are silent (no version bump enforced).

This loop combines the two A8 tickets (`TMX-3200` registry layout + `TMX-3201` migration) into one ship because they're tightly coupled: there's no value in the layout without the migration, and no value in the migration without the layout.

## 3. Design

**Package vs file collision**: `app/agents/prompts.py` (file) and `app/agents/prompts/` (package) cannot coexist — Python's import system picks one. Solution: delete the `.py` file and create the package. The package's `__init__.py` exposes `PromptRegistry` and `PromptVersion` so `from app.agents.prompts import PromptRegistry` works.

**Loader API**:

```python
@dataclass(frozen=True)
class PromptVersion:
    agent: str
    version: str        # semver "1.0.0"
    system: str
    user: str
    content_hash: str   # sha256(system + "\n---\n" + user) [hex]

class PromptRegistry:
    @classmethod
    def load(cls, agent: str, version: str = "latest") -> PromptVersion: ...
    @classmethod
    def list_versions(cls, agent: str) -> list[str]: ...

class PromptNotFoundError(LookupError): ...
class PromptSchemaError(ValueError): ...
```

The registry is a class with classmethods (no instance state) — cache via class-level dict. One read per `(agent, version)` per process.

**Why `content_hash = sha256(system + "\n---\n" + user)`**: deterministic, surfaces in JobConfigSnapshot as a non-PII fingerprint that lets a regulator distinguish two identical-version-string-but-different-content edits. The `\n---\n` separator avoids the case where moving content from system into user produces the same hash.

**Why dataclass frozen**: prevents accidental mutation post-load (the registry returns the same object to repeat callers; mutation would corrupt the cache).

**Why semver "latest" via simple lex sort over `vX.Y.Z` filenames**: semver lexsort works for the strict `X.Y.Z` format we control. We don't need pre-release tags or build metadata in this loop.

**Why migrate `REVIEWER_*` even though unused**: A8 asks for *every* prompt to be pinned. Leaving an inline-constant prompt in the codebase in the same loop that establishes the registry creates two sources-of-truth and undermines the discipline. Cost is one YAML file.

## 6. Red team

Walked Tier 2 22-item checklist. Findings:

- **CLEAN — all 22 items PASS or FIXED for TMX-3200 + TMX-3201.**
- 💡 **Behaviour change captured (intentional)**: original `TRANSLATOR_SYSTEM_V1` was a Python triple-quoted string with a leading `\n` (because the `"""` was followed immediately by a newline). YAML literal-block syntax (`|`) does NOT produce a leading newline. The migrated prompt is therefore 1 byte shorter at the start of each system block. Per AC-6 this is "modulo YAML literal-block semantics" — explicitly allowed. LLMs do not meaningfully differ in output for a leading newline. The new content_hash captures this canonical form.
- 💡 **graph.py `_build_translation_prompt` was missing `{{language_instruction}}` substitution** before this loop. The legacy code raced past the placeholder, leaving `{{language_instruction}}` literal in the prompt sent to the LLM. Quietly a real defect — the language-pack instruction (e.g. Spanish formal register) was never injected into the translator agent except via `translation_engine.py:_build_prompt`. **Loop fixed it inline** (added `.replace("{{language_instruction}}", "")` so the placeholder is at minimum stripped, even when the pod doesn't pass an instruction). Same pattern in `batch_translator.py`. **Spawning TMX-3204** to wire `lang_instruction` into both call sites — the placeholder being substituted to empty-string is a stop-gap, not the right design.
- 💡 **A8 follow-up needed (TMX-3202)**: this loop established the registry; the JobConfigSnapshot capture site at `app/agents/graph.py:140-143` still has `"prompts_version": "v1.0"` hard-coded. TMX-3202 (sister of TMX-3212/3213) wires `prompt.version` and `prompt.content_hash` into the snapshot. **Out of scope here** — audit-pod territory; my pod boundary stops at exposing the content_hash.
