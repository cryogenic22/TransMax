## 3. Design

**Why extend, not replace**: the existing Google Blue palette is already coherent and matches a serious-tech-product posture (rescape's option 1 in their Strategic Direction 1). Replacing it loses signal. Extending it with TransMax-specific tokens layers brand identity on top.

**AI gradient choice**: the rescape review notes their AI surfaces use "soft purple gradient on the AI sparkle icon". For TransMax, we use a **violet → cyan** gradient (`#8b5cf6 → #06b6d4`) — distinct from rescape (different brand) but still sits in the "this is AI" colour family that has become an industry signal (OpenAI, Anthropic, GitHub Copilot). The gradient gets used on every AI-generated artefact (translation output, defect explanation, suggested fix, model+prompt provenance chip).

**Status lifecycle palette**: 6 states, each with a hue + saturation that scans at a glance:
- `pending` neutral grey
- `translating` violet (in-progress AI work)
- `translated` blue (AI output, awaiting human)
- `reviewed` teal (human seen, not yet decided)
- `approved` green (human signed off)
- `blocked` red (critical defect / cannot proceed)

**Agent identity colours**: 4 agents in our LangGraph today (translator, reviewer, fixer, auditor). Each gets a distinct hue used on swimlanes / activity-feed avatars / OTel-span chips:
- translator → violet (creative — pairs with AI gradient)
- reviewer → blue (deterministic gates)
- fixer → amber (corrective)
- auditor → emerald (compliance)

**Brand mark**: a stylised geometric "TM" monogram, two glyphs forming a single shape, set in a rounded square. Scales to 24px, reads as a brand mark not a doc icon.

**Why no extra type pair this loop**: the existing DM Sans + JetBrains Mono pair is pleasant and cohesive. The rescape review's "pick a workhorse + display pair" recommendation requires a deliberate design call we don't need to make today; today's pair is the workhorse, and a future loop can introduce a display face if needed (Tiempos Headline or similar).
