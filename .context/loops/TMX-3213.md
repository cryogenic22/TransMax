**Reversibility**: `two-way` — code-only; computes a real hash for a *new* event's payload field that was previously a literal. No schema change, no history rewrite, no chain-link change. Revert = restore the literal.
**Pre-mortem**: if this fails in production, the failure mode is a wrong/empty `output_hash` on the terminal `JOB_FINALIZED` event (a weaker audit anchor than intended) — never a pipeline crash (the hash is pure + total over the in-memory segments). It cannot corrupt earlier events.
**Blast radius**: `app/agents/graph.py` (`finalize_job` + one new pure helper `_compute_output_hash`), new `tests/test_finalize_output_hash.py`. Touches the audit chain (A1) — sensitive surface; no other behaviour changes.

**Loop-driven-dev gates**:
- [x] **G1 Anti-bloat** — (trust) the terminal audit event is the regulator's anchor to the actual artifact; a placeholder makes the chain's last link non-evidential. One pure helper, no new dependency, mirrors `audit_service`'s existing `sha256(json.dumps(...,sort_keys=True))` idiom. Passes the trust + robustness tests of the five-test rubric.
- [x] **G2 Reproduce-the-failure** — `finalize_job` currently writes `"output_hash": "placeholder_hash"` into both the legacy `log_event` and the v2 chain emit (graph.py:578). A RED test asserts the emitted hash is a real sha256 of the output, which fails on the literal.
- [x] **G3 Completion** — `JOB_FINALIZED` (legacy + v2) carries a 64-hex sha256 that equals `_compute_output_hash(state.segments)`; the value is deterministic and order-stable; no remaining `"placeholder_hash"` literal under `app/`. Proven by `tests/test_finalize_output_hash.py` (7 tests) + the static guard.

## 1. Task

## 2. Spec — acceptance criteria
- [ ] AC-1: a new pure `_compute_output_hash(segments)` returns a 64-char lowercase hex sha256, deterministic for the same ordered output, order-stable (sorted by `order_index` then `segment_id`).
- [ ] AC-2: `finalize_job` writes that hash into `final_payload["output_hash"]` — consumed by BOTH the legacy `log_event("JOB_FINALIZED", …)` and the v2 `_emit_v2_audit_event(...)`.
- [ ] AC-3: no `"placeholder_hash"` literal remains under `app/` (static guard).
- [ ] AC-4: empty/zero-segment job → a stable hash of the empty canonical form (never raises).

Out of scope: rewriting the v2 chain hashing (E2); hashing the exported binary artefact (separate from the segment-text anchor).

## 3. Design
Mirror `audit_service` hashing: canonicalise the ordered `(order_index, segment_id, translated_text)` triples to `json.dumps(..., sort_keys=True, ensure_ascii=False)`, sha256 it. Pure + total. Add `import hashlib` to graph.py (`json` already imported). Replace the one literal at the single payload-construction site so both sinks inherit the real value.

Rejected: hashing the exported DOCX/PDF bytes here (the finalize node operates on segment state, not the rendered file; the export-side anchor is a separate concern) — kept the anchor at the segment-text layer, which is what the event certifies.
