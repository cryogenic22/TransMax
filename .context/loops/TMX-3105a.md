## 1. Task
Spawned by TMX-3105. Add a single machine-stable `status` headline and `chain_head_hash` so a compliance dashboard renders a badge + an anchorable hash without walking `findings`.

## 2. Spec
- AC-1: clean chain → `status="OK"` + `chain_head_hash == hex(highest-seq event_hash)`.
- AC-2: payload/event-hash tamper → `status="TAMPERED"`.
- AC-3: deleted middle event → `status="SEQUENCE_GAP"` (precedence over co-occurring tamper).
- AC-4: `ok == (status == "OK")`; head hash is null only for an empty chain.

## 3. Design
`_derive_status(findings, event_count)`: empty→EMPTY, none→OK, any sequence_gap/duplicate→SEQUENCE_GAP, else TAMPERED. Sequence precedence first (a missing event is a more structural defect than an altered one). Head hash read under the same tenant-scoped session (no cross-tenant leak).
